# 蒲公英的约定 - 钢琴键编码说明

## 概述

本项目使用自定义的简谱编码系统来描述音符，每个编码对应钢琴上的一个琴键和音频文件。

## 编码规则

### 1. 基本音（数字 1-7）

数字 1-7 对应钢琴的白键：

| 数字 | 音符 | 音名 |
|------|------|------|
| 1 | C | Do |
| 2 | D | Re |
| 3 | E | Mi |
| 4 | F | Fa |
| 5 | G | Sol |
| 6 | A | La |
| 7 | B | Si |

### 2. 音域修饰符

#### `+` 前缀 - 升八度

`+` 表示音符升高一个八度（+1 到 +7）：

| 编码 | 含义 | 示例 |
|------|------|------|
| `+1` | C5 (高八度 Do) | E5 |
| `+3` | E5 (高八度 Mi) | G5 |
| `+5` | G5 (高八度 Sol) | B5 |

#### `-` 前缀 - 降八度

`-` 表示音符降低一个八度：

| 编码 | 含义 | 示例 |
|------|------|------|
| `-1` | C3 (低八度 Do) | D3 |
| `-5` | G3 (低八度 Sol) | A3 |

### 3. 半音修饰符

#### `#` - 升半音（sharp）

`#` 将音符升高半音：

| 编码 | 含义 | 对应黑键 |
|------|------|----------|
| `#1` 或 `#4` | C# / F# | 右侧黑键 |
| `#2` 或 `#5` | D# / G# | 右侧黑键 |
| `#3` 或 `#6` | E# / A# | 右侧黑键 |

#### `-` 中缀 - 降半音

`-` 在数字间使用时表示降半音：

| 编码 | 含义 |
|------|------|
| `3-#6` | E - A♭ (降 A) |
| `1-5` | C - F (降 F) |

### 4. 时值修饰符

#### `.` - 延长点

点号表示音符延长：

| 编码 | 时值 | 说明 |
|------|------|------|
| 无点 | 500ms | 四分音符 |
| `1个点` | 1000ms | 二分音符（延长一拍） |
| `2个点` | 1500ms | 延长的二分音符（延长两拍） |

示例：
- `3` = 500ms
- `3.` = 1000ms
- `3..` = 1500ms

### 5. 复合编码

多个修饰符可以组合使用：

| 编码 | 解析 | 含义 |
|------|------|------|
| `+3.6.3.-4` | `+3.` + `6` + `3` + `-4` | E5(1000ms) + A5 + E5 + F4 |
| `+1#41--#4` | `+1` + `#4` + `1` + `--#4` | C5 + F#5 + C5 + F♭♭4 |
| `+274-5` | `+2` + `74` + `-5` | D5 + B4 + G4 |

## 键盘映射

### 键盘到琴键的对应

项目中定义了键盘按键到钢琴音符的映射关系：

```
┌─────────────────────────────────────────────────────────────┐
│  键盘按键          │  低音域(Ctrl) │ 中音域   │ 高音域(Shift) │
├─────────────────────────────────────────────────────────────┤
│  1              │     C3        │   C4     │     C5        │
│  2              │     D3        │   D4     │     D5        │
│  3              │     E3        │   E4     │     E5        │
│  4              │     F3        │   F4     │     F5        │
│  5              │     G3        │   G4     │     G5        │
│  6              │     A3        │   A4     │     A5        │
│  7              │     B3        │   B4     │     B5        │
├─────────────────────────────────────────────────────────────┤
│  Q (q)          │    C#3       │   C#4    │     C#5       │
│  W (w)          │    D#3       │   D#4    │     D#5       │
│  E (e)          │    F#3       │   F#4    │     F#5       │
│  R (r)          │    G#3       │   G#4    │     G#5       │
│  T (t)          │    A#3       │   A#4    │     A#5       │
└─────────────────────────────────────────────────────────────┘
```

### 修饰键组合

通过组合修饰键可以访问不同的音域：

| 修饰键 | 效果 |
|--------|------|
| 无修饰键 | 中音域 (C4-B4) |
| Shift | 高音域 (C5-B5) |
| Ctrl | 低音域 (C3-B3) |
| Alt | 次高音域 (C6-B6) |
| Command | 最高音域 (C7-B7) |

## 编码解析示例

以 `pgydyd.js` 中的编码为例：

```
'3', '5', '+1', '+3', '+3.6.3.--4'
```

解析过程：

1. `'3'` → E4 (500ms)
2. `'5'` → G4 (500ms)
3. `'+1'` → C5 (500ms)
4. `'+3'` → E5 (500ms)
5. `'+3.6.3.--4'` 包含4个音符：
   - `'+3.'` → E5 (1000ms，延长音)
   - `'6'` → A4 (500ms)
   - `'3'` → E4 (500ms)
   - `'--4'` → F♭4 (500ms，降两次半音)

## 时值计算规则

```javascript
  case 2: time = 1500ms; break;

加号(+)数量: 升高八度

// 半音计算
# 数量 > 0: 升半音
```
